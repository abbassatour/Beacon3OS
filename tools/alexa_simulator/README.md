
# 🎙️ Alexa+ Echo Show Multimodal Simulator

A zero-install Web Application simulating an **Amazon Echo Show** device communicating with **BeaconOS** via the **Model Context Protocol (MCP)** Streamable HTTP transport (Spec: `2025-11-25`).

## ✨ Features

1. **Echo Show UI**: Dark WCAG AAA display with ambient Alexa Cyan lighting.
2. **MCP Apps Multimodal Cards**: In-line visual cards for phone locator radar, telemetry gauges, and emergency dashboards.
3. **Voice Interaction**: Web Speech API for hands-free voice commands and Alexa speech playback.
4. **Live Protocol Inspector**: Real-time logging of JSON-RPC 2.0 payloads for hackathon judges.

## 🚀 How to Run

1. Start the MCP Server:

```bash
cd mcp_server
python server.py
```
